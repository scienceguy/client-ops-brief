Questions

Do I need a specific AI tool?

No. Every workflow is written as a prompt plus a process. Use OpenCode, Claude, ChatGPT, Gemini, or a local model. If the tool can read text and return text, it works.

Is this just a prompt pack?

No. A prompt without a trigger, an input contract, a review step, and a definition of done is a toy. Each workflow includes all five.

Will this work for my niche?

The workflows are for client services: consulting, fractional work, design, development, marketing, and small agencies. The examples use consulting, but the structure transfers. Edit the context block once per client.

How long does setup take?

Fifteen minutes for the first workflow. The full kit is designed to be rolled out over 30 days, one workflow per week, not installed all at once.

What about client confidentiality?

The kit includes a redaction checklist. Use a local model or a business account with data controls for sensitive material. Never paste anything you are not allowed to process.
